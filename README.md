# Mark Mutinda — Portfolio

An editorial one-page portfolio, built with Next.js and styled in muted sage, warm cream, and deep burgundy.

## Local setup

```bash
npm install
npm run dev
```

Visit http://localhost:3000.

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. Import that repository at https://vercel.com/new.
3. Leave the framework preset at **Next.js**, then deploy.

## Customize before publishing

- `app/page.tsx`: project descriptions, statuses, personal story, university timeline, contact links. Replace the tentative descriptions for Njia and AlcoTrack with confirmed details.
- `app/globals.css`: colours, typography, layout, responsive styles.
- `app/layout.tsx`: metadata and social preview copy.
- Add authentic project screenshots and real repository/demo links when ready; decorative artwork currently serves as visual placeholders.
- Add your real CV PDF to `public/cv.pdf` and a visible download link when ready.
- Check your personal contact email is one you want to publish.

The project uses CSS animations/transitions only; no extra animation dependency is needed.
